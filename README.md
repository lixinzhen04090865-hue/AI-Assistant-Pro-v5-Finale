# 🤖 AI-Assistant-Pro (v5-Finale)

> **可能是全网最硬核的单文件(SFA)原生 AI 客户端。**
> 0 依赖，0 部署，双击即用。

## 📜 为什么造这个轮子？
高中学校的机房环境极其受限，不仅每次重启都会还原，而且完全没有条件去配 Node.js 或者安装 Vue/React 脚手架。为了能在学校随时插上 U 盘调用 API 讲讲物理错题，我决定用**纯原生 Vanilla JS** 手搓一个客户端。

之前前四个版本都是在班里同学的 U 盘里拷来拷去。最近刚好迭代到了 V5 版本，被大家怂恿着开源。下周马上就要面临“苏锡常镇一模”的理综拷打了，趁着周末稍微喘口气，注册了 GitHub 把源码传上来留个纪念。

## 🛠️ 硬核特性
本文件共计近 2000 行纯 HTML/CSS/JS 代码，未引入任何外部框架：
- **⚡ 原生 SSE 流式解析：** 纯手写 `fetch` 和 `ReadableStream` 配合，告别卡顿的打字机效果。
- **🧠 深度思考 UI (适配 R1)：** 专门针对类似 DeepSeek-R1 等带有思维链的模型，手写了“思考过程”的折叠与计时动画。
- **💾 本地记忆系统：** 对话历史与设定的用户偏好全部走 `localStorage`，断网可用，隐私绝对安全。
- **📝 原生 Markdown 渲染 & Canvas 编辑：** 用正则手搓的代码高亮和排版解析，甚至支持代码块的原生编辑与另存为。

## 🚀 怎么运行？
拔掉网线，插上 U 盘，双击 `AI-Assistant-Pro-v5-Finale.html`，输入你的 API Key，直接起飞。
